# LinkedIn Company Cleaner by Clintware

A Manifest V3 extension for Microsoft Edge, Google Chrome, Brave, Vivaldi, and other Chromium browsers. It finds only LinkedIn company Pages in your own following list, lets you select specific companies or all found companies, and handles LinkedIn's repeated Unfollow prompts after one confirmation for the run.

## Download

- `linkedin-company-cleaner-v1.0.0.zip`
- SHA-256: `1c62a20d0a4d7b55b093f0508f8c1ffb0de75ca40d6d963d33947b5b26903637`

The ZIP contains the complete unpacked extension source with `manifest.json` at its root.

## Scope

- Company Pages only: `/company/` URLs
- Ignores people, schools, groups, newsletters, and skills
- Local browser processing only
- No analytics, tracking, external APIs, or remote code
- Per-run maximum, randomized delay, auto-scroll, progress, and stop controls

## Install

1. Download and extract the ZIP.
2. Open `edge://extensions` or `chrome://extensions`.
3. Enable Developer mode.
4. Choose **Load unpacked**.
5. Select the extracted folder containing `manifest.json`.

## Compatibility

LinkedIn changes its interface frequently, so this tool may require updates. LinkedIn's published rules state that it does not permit browser extensions that automate activity on its website. This independent project is not affiliated with or authorized by LinkedIn.
